# Cargo TMS (NetBeans / Java Swing)

## Chạy bằng NetBeans
1. Mở NetBeans -> **Open Project** -> chọn thư mục dự án này.
2. NetBeans nhận diện dự án Maven (`pom.xml`).
3. Chạy lớp `com.cargo.tms.Main`.

## Tính năng
- Tạo vận đơn hàng hóa.
- Xóa vận đơn được chọn.
- Dashboard tổng hợp (tổng đơn, đơn đang vận chuyển, giao thành công, doanh thu, tổng khối lượng).
- Lưu dữ liệu ra `shipments.csv` và tự nạp lại khi mở app.
